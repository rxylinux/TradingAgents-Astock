## 结论

最值得增加的能力依次是：**每条关键证据可追溯、关键数字可复算、结论附明确反证条件、样本外评测能判定改动是否有效**。目前已有七角色、辩论和结构化决策；再加角色并不能自然消除数据时点泄漏、计算错误或共同引用同一错误来源的问题。

以下收益都是待验证假设。工程测试能证明时间过滤、证据引用和计算契约正确，不能证明投资收益或预测准确率已经提高。无真实冻结数据和前瞻样本时，报告明确写“效果尚未验证”。

## A：真实历史新闻与失败语义

详细要求见 [优化审核](OPTIMIZATION_REVIEW_2026-09-08.md)。先过滤时间、再去重/限量；输出发布时间与来源；缺失/非法时间隔离；请求失败、成功空结果、窗口覆盖不足明确区分。所有相关时间统一到亚洲上海日界线：日期精度输入明确为日期级，带 offset/Z 输入按真实时间换算；不通过截取前十位接受损坏尾部。

独立审核须覆盖：UTC 与上海跨日、非法尾部/无效小时、未来同标题先出现、窗口外记录占满 limit、所有时间 unknown、双源失败、单源失败且另一源为空、部分源可用、真实 tool invoke 和缓存失败识别。partial 来源失败应保留说明，不能声称来源完备；实时资讯端点为空不等于历史全市场无新闻。后续 C1 再将这些限制结构化。

## C1：证据账本与决策引用（N07 首批，下一编码任务）

### 用户可见结果

新闻报告与最终结论可展示“依据何条新闻、何时发布、何时抓取、哪些来源失败/时间未知”；保存 JSON、Web 和 Markdown 共用同一结构。暂不把所有工具一次性重构。

### 最小范围与接入

1. 新建不依赖 UI 的证据契约与构造/校验/渲染模块。先接个股/宏观新闻两个实际工具，在保留现有工具字符串接口的情况下提供真实结构化结果；由调用路径显式传递至运行状态，禁止全局可变列表，不能从 LLM 报告猜造 provenance。先画清实际 LangGraph ToolNode→AgentState 通路并用离线双运行演示，再编码。
2. `evidence_bundle` 有版本、run_id、analysis cutoff 与 scope；records 至少含 evidence_id、source、source_record_id（可缺）、title、excerpt、url（可缺）、published_at（可缺）、time_precision（date/datetime/unknown）、timezone、retrieved_at、content_digest、availability。digest 用稳定规范内容生成；同文跨来源仍保留出处。source URL 不存在时留空，不构造看似真实的链接。
3. `source_status` 分开记录 successful/empty/failed/partial 与覆盖限制；时间未知、窗口外、来源失败的计数分别保存。不把未来正文送入模型；可以保留排除计数/原因，但历史输入不含被排除的未来事件标题/摘要。
4. 发布时间不等于历史可得时间。若没有原始快照，只能标记 `availability=publication_time_only`；不可声称是严格 point-in-time。首次抓取在 cutoff 之后本身不证明当时已可用，修订文本也不能冒充当时原文。旧报告缺字段显示 unknown。
5. 证据 ID 在同一规范记录内容下稳定；内容修订导致 digest/ID 变化，相关引用不能继续指向旧事实。截断正文需标记且保留稳定原始摘要 digest；不得保存 Cookie、headers、认证 URL query。
6. 将精简合法证据索引和明确限制交给研究经理/交易员/组合经理；输出引用可做“ID 存在且时点合规”的确定性检查。必须明确“引用有效”不等于“声明受支持”，不要复用 N04 的 supported 术语冒充事实判断。
7. 报告保存沿用 N02 的版本化出口。Web 与 Markdown展示来源列表/限制，旧报告兼容；PDF至少通过已有共用 Markdown 出口保留信息。不做新的数据库或联网爬虫。

### 验收

两次并发运行不串证据；fresh 与恢复语义清楚；没有新闻分析师时不伪造证据；两工具同条去重仍保留来源；跨源转载不算多份独立支持；原文变更 ID 变化；unknown 时间/来源故障不消失；历史输入剔除未来正文；旧状态/旧 JSON 能加载；引用不存在 ID 被标记；真实工具到 JSON/Web/Markdown 的端到端离线 fixture。测试不得只调用新纯函数而绕开真实图接入。

## C2：研究假设卡、评估状态与反证（N08 首批）

结论增加结构化 thesis：适用标的、形成时间、明确预测期限、主要论点、supporting/contradicting evidence_ids、待验证假设、催化事件、失效条件、下次检查触发点。字段无资料就 unknown，不让模型补出虚构价格、财报日期或概率。

单独提供 `assessment_status=assessable/limited/insufficient/unknown` 与原因；沿用当前 action，资料不足不强制改 Hold，更不能把 Hold 当成“模型谨慎且准确”。代码依据可观察缺口生成限制，LLM 自称高信心不能覆盖。`confidence` 若仅为模型自述，应明确 `uncalibrated`；没有样本外校准时不显示投资胜率。

失效条件需可观察：如“下一已披露季度经营现金流同比转负”，应包含指标、比较符、阈值、期间/触发事件、所需来源与证据；自由文本条件只标“待人工判断”，不声称自动触发。首批仅生成与展示，不订阅数据、不创建交易、不发送外部提醒。

验收：引用悬空/未来/冲突；缺输入不臆造；同一结论不同期限独立；多空证据并存；状态、文本与各出口一致；受限判断不能被下游改写冲掉；旧报告兼容。沿用已有结构化调用，避免为格式增加一次 LLM 调用。

## D：可复算的财务指标与情景估值

先以确定性纯函数+显式输入清单实现：同比增长、利润率、经营现金流/净利润、净现金/净债务、合理估值区间。每个数值附单位、币种、合并口径、报告期间、披露时间与 evidence_id。缺少匹配期间、分母为零、负利润、跨币种未给汇率、未经披露数据→unknown/不适用，不静默补零。不同报告期不能直接相减冒充季度值，TTM 必须有完整可兼容输入。

第一版估值仅支持用户/fixture 明确给定的盈利与倍数情景（悲观/基准/乐观），完整列出假设及敏感性，不默认倍数、不造债务。DCF 单列后续，待现金流、折现率和资本结构输入可靠再做。指数不套个股财报公式。最终报告引用计算结果与输入，不允许 LLM 在文案中重新心算覆盖。

效果评估先看数值错误率、口径缺失率、无法计算率和可追溯率；区间更精细不等于预测更准。数据实际抓取接入在 C1 模式稳定后单独界定，不能以事后修订财报做历史回测。

## E：独立初判、分歧定位与有界反证补查

多空双方先根据同一时点内证据独立形成结构化初判，再展示彼此意见。经理产出 disagreement 列表：冲突 claim/来源/期间、待核实问题、哪个答案会改变结论。优先补查能影响决策的缺口，限制最多 2 个问题、每个 1 次工具轮、单独 token/工具预算；达到上限保留 unresolved，不能无限辩论。

必须从当前已配置的数据工具中选择，不扩大网络权限。来源转载和重复报道不投票；官方披露优先仅是来源权重规则，不保证其完整或没有修订。冲突不强行平均数字。单独 A/B 比较与原辩论机制，避免同时改变模型和数据源而无法归因。

## F：记忆与效果评测

复盘记录最少包含当时 thesis、预测期限、可得证据版本、实际结果观察窗口、benchmark、费用假设、最大不利变动与错误类型（数据缺失/时点/计算/推理/执行/市场不可预见）。未到期限标 pending，不当成成功或失败。盈利不等于推理正确，亏损不自动删除正确风险判断。

检索只用 as-of 时刻前已成熟记录；按相关性、市场状态、事件有效期检索，旧事件过期。修改重要性/衰减规则必须留版本与实验记录，不在生产记忆上试调。

接续现有 N04，新增独立评测层而不改变其“契约≠预测能力”的口径：

- 固定股票/指数、牛熊震荡、行业、缺失数据案例，按日期训练/验证/留出，禁止随机打散跨越未来；预测窗口重叠要隔离，保留基线与候选配对。
- 同一数据快照、公开配置、预算、模型版本和多次试验；数据源差异另报。研究代码不得读取留出标签。
- 报告事实支持率（人工/独立标注）、时点违规率、数值错误率、冲突未解决率、完成率、延迟与成本；准确度须与评估覆盖率一起报，拒答更多不能只报留下样本的高准确率。
- 方向/收益评价明确期限与基准；A 股开盘可成交时间、T+1、涨跌停/停牌、复权/分红、交易费用与退市样本按预先声明规则处理，避免幸存者偏差。数据缺口时结果 unknown。
- 若给事件概率，需事先定义可验证二元事件，再算 Brier/校准曲线与置信区间；不能对含糊 Buy/Hold 文案计算胜率。
- 首批仅离线与合成契约演示，真实数据快照和模型实验另列已授权范围核对。不能用合成随机收益展示“提高准确率”。
