# 历史报告对比使用说明

## Web 界面

1. **入口**：在空闲首页或查看任一历史报告时，点击「🔄 对比两份历史报告」。
2. **选择**：在左右两个下拉框中各选一份报告（默认选择不同版本）。
3. **对比**：点击「对比」按钮，查看差异结果（评级、配置、质量、正文变化）。
4. **下载**：点击「⬇️ 下载对比 Markdown」保存对比结果为文件。
5. **返回**：点击「← 返回单份报告」回到之前查看的报告。

注意：分析运行期间无法进入对比；历史报告页的对比按钮会暂时禁用。

## 命令行

```bash
# 输出到终端
python -m tradingagents.report_comparison report_A.json report_B.json

# 保存到文件
python -m tradingagents.report_comparison report_A.json report_B.json --output comparison.md
```

退出码：`0` 成功；`1` 报告不可比较、输出路径与输入冲突或输出写入失败；`2` 参数错误或输入报告无法读取/解析。输出文件不要与任一输入报告重名。

## 比较条件

- 只比较**同一标的 + 同一类型**（个股 vs 指数拒绝；不同分析日期允许）
- 报告质量状态反映的是**报告完整性**（长度/表格/失败标记等硬信号），
  不是事实准确率、投资胜率或模型能力
- 配置不同或元数据缺失时明确标注比较条件差异
- 兼容旧报告格式；缺少配置、质量检查或分析师启用记录时会标注未知
