## G2：财报标准化与可选面板接入

1. 先提交来源字段映射表：来源原字段、真实样例、单位依据、合并／母公司口径、期间类别、披露／修订时间来源、缺失处理。现有来源不提供的元数据必须缺失，不以“通常如此”填充。来源样例必须注明合成或实际抓取，不伪造官方来源。
2. 首版只处理沪深 A 股、CNY、明确日历年度与明确报表口径。映射 revenue/net_profit/net_profit_total/ocf/cash/short_term_borrowing/long_term_borrowing/bonds_payable；`non_current_debt_due_within_1y` 只有明确的有息部分可映射，总的一年内到期非流动负债不得冒充。EPS(TTM) 和估值倍数不从缺失数据猜造。
3. 字符串数值由边界适配器严格解析，拒绝 bool/非有限值/歧义单位；转换到 D1 类型时应保证表示精度，不能浮点往返悄悄改数。Q3/H1 累计值不当作单季度；不在本批新增 TTM/EPS 推导公式。
4. 先筛选时点、再选择版本；G1 存档保留所有版本，G2 对无法确认重述关系的同槽冲突返回明确限制。首版对重述链不生成 D1 输入，不把 `restated=true` 改成 false 过验证；完整历史版本选择另行补契约。
5. 产物为 `manifest.json`（仅 D1 合法输入）与绑定其摘要的来源／排除侧车文件。每条 `offline_ref` 必须可定位到 G1 快照和字段；D1 保持纯计算，不为解析 provenance 隐式读文件或联网。零合格输入时产生缺失诊断，不伪造空成功面板。
6. 新 CLI/Web 选项显式启用，默认不联网、不改变现有手工 manifest 行为；两种输入同时提供应明确拒绝。CLI 与 Web 共用准备函数；恢复只用已保存快照，原文件删除后仍可恢复，不静默重新抓取。
7. 显示抓取来源与时间、声明披露时间、单位、口径、排除原因。Sina 聚合财报不等于交易所公告原文；若没有原公告链接/页码，留空并说明。本轮 G 不承诺通用 PDF/OCR 公告抽取。

验收：来源字符串／万元／亿元转换、归母与总利润区分、累计与季度区分、缺债务项、未知单位／口径／披露时间、同期间冲突、修订晚于截止、未来行不进提示词、原始字段到报告可定位、实际 CLI 与 Web 准备链、关闭路径与断点恢复。

## H1/H2：运行账本与预算

H1：核心账本不依赖 Streamlit，事件以 run_id、attempt_id、parent_attempt_id、role、provider、model、event_id 归属；逻辑调用和真实 HTTP 尝试分开。记录开始／结束／失败、已知用量、未知字段、耗时与停止原因。持久存储首选 stdlib SQLite 事务，绑定 schema_version，终态 completed/failed/cancelled/budget_exhausted/interrupted 明确。重复回调幂等，迟到回调仍归属原运行；禁止归入 UI 当前选中的另一运行。

费用只有显式定价表且 provider/model/日期匹配时计算，保存价格版本和币种。Decimal 计算；已知费用与缺失用量分开，不默认零、不把订阅调用当免费、不跨币种相加。失败和取消后账本保留；与现有 UI 清理可见进度分离。首次仅记录必要元数据，不落 API key、headers、完整提示词或私有响应正文。

H2：全局控制对象在真正发送请求前原子预留配额；覆盖结构化 fallback、工具、供应商内部重试和并发分支，禁止 wrapper/SDK 双计或漏计。timeout 取剩余 deadline 与原 timeout 较小者。调用数能硬限制；token 只有可证明的输入估计和输出上限时才能硬预留，不可观测 provider 明确不支持硬 token 限额，不能承诺精确费用封顶。停止后不发新请求，不能取消的在途请求显示 stopping 并在返回后结算；不声称远端计算立即停止。

首版分 provider 交付能力矩阵，未覆盖 provider 不得被展示成支持全链预算。恢复不重置已花费配额；历史用量未知的恢复不允许冒充精确剩余预算。Web/CLI 输入边界一致，非法负数/bool/NaN/0语义明确。

验收：两运行并发隔离、配额边界争抢、重试+fallback 真实传输计数、取消时在途返回、重启恢复、callback 缺失/重复/迟到、失败后账本可查、未知用量费用不造零、非支持 provider 显式状态。采用假传输与可控时钟，不使用付费模型测限额。

## I1/I2：假设检查与变化说明

I1 首版只认白名单指标、比较符、明确期间与阈值；输入为已保存 C2 卡、新 G2/D1 面板和可信检查时点。condition_id 由规范条件内容决定，不按列表序号认同一条件。原始假设不可变；用户修改条件形成新版本，不覆盖上次预测。

状态分别为 triggered/not_triggered/pending/unknown/manual_review，未知不等于未触发。缺输入、未到披露事件、单位/口径不兼容、无数据均单独说明；解释为确定性模板，保留原值、阈值、来源和时点，不增加模型调用。检查只陈述条件真假，不自动把评级改成卖出，也不宣称这是评级变化的因果证明。

I2 扩展已有报告对比：同标的同类型，按条件内容身份显示新增／删除／保持／首次触发／解除；条件改变时不冒充同条件状态逆转。首版手动“检查更新”和应用内列表，不创建 OS 定时任务、不发送微信邮件。事件按条件版本＋输入版本＋状态转换去重，重放不重复提醒；页面切换不展示前一标的迟到结果。

验收：不同报告条件重排、同 ID 不同内容、阈值改动、边界相等、未到期、缺失、负数、未知口径、未来披露、不同股票、重复检查、旧报告无假设卡、已有报告对比不退化。

## J：有界批量研究

持久队列包含 job_id、item_id、输入摘要、运行身份、状态和尝试；默认最大并发 2、一次最多 20 标的，配置可降低，不首版无限扩容。去重键包含标的、类型、分析时点、配置与输入快照身份；同股不同日期不是重复任务。

状态 queued/running/succeeded/failed/cancelled/interrupted；进程重启将失去租约的 running 标 interrupted，由显式重试恢复，不造成功。单项失败不重跑成功项。总预算和每项预算都经 H2；取消队列不取消别的用户单次分析。同键宏观数据可共享不可变抓取快照，共享键必须含 as-of/窗口/来源/参数；失败结果不当成功长期缓存。

复用真实分析入口与报告出口，不以假报告演示冒充批量联通。先离线替身验收，真实付费运行仍遵循模型预算授权。

## K1/K2：前瞻记录、标注与真实评测桥接

K1 显式启用后记录真实 run_id、模型和安全配置、输入快照、决策、预测期限、记录时间与内容摘要，原版本不可变。历史导入标 backfilled，合成数据标 synthetic，不可修改为 prospective。摘要只能证明内容一致，不能证明历史真实性；本地时间是记录声明，不宣称第三方时间认证。

结果成熟需明确窗口和可得时间；自动判断 pending，不自动生成 supported/win 标签。人工标注精确绑定 claim/reference/run 与输入摘要，保存标注人、时间、版本和冲突。盈亏、推理正确、风险提示正确分别记录。

K2 桥接已有 F3 的实际 schema 与支持配置范围，先只做 E 开关配对。计划冻结在标签读取前，同一快照两臂、多次重复、缺失/失败仍保留分母和成本；没有完整冻结模型输入时不得声称公平对照。可用预算明确后才启动真实模型实验。行情结果先显式导入，不在首版宣称带交易制度、费用和可成交性的完整回测；没有这些输入不输出策略净收益。

验收：保存/恢复同一身份、输出缺失、模型/配置不匹配、事后导入标记、标签改动版本、未来标签隔离、真实 prepare→导出→score 产物摘要、覆盖率与费用组求和恒等式。Brier 仍保持未实现，不把文字信心换成概率。

## L/M：后续功能的有限范围

L 首版做结构化数值引用核验与人工事实标注：数字、单位、币种、期间、口径全部匹配才 numeric_verified；数字核验不升级为整句事实正确。自由文本因果／预测推断保留 unverified/manual_review；不以模型自评作为独立事实依据。

M 首版只接受用户显式提供的持仓文件、估值日期、价格和汇率，计算权重、行业集中、共同风险标签与资料覆盖。缺价格/汇率不换算，未知行业单列；基金穿透没有底层数据则不做。持仓读入不得自动发送到模型；首版本地确定性计算与已有报告引用。风险标签共现不等于统计相关系数；不生成自动订单或自动调仓。
