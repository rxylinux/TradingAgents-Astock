## 六项修复（`tradingagents/agents/thesis.py` + `tradingagents/evidence/ledger.py`）

1. **占位期限不算已声明**：`time_horizon` 经 `_norm_placeholder` 归一（空白/`unknown`/`未知`/`n/a`/`none`/`-`/`待定` 等占位 → None）。卡片保留原文 `prediction_horizon_raw` 供审计、不臆造；`prediction_horizon` 归一后为 unknown；占位 → gap `horizon_placeholder` → limited。
2. **条件字段占位不算可观察**：同一占位归一作用于 indicator/comparator/threshold/period/source——五字段占位值计为缺失。
3. **缺观察来源 → 待人工判断**：可观察性判定加入 `source`（任务书"所需来源与证据"）；缺来源保留条件并标 manual_review，不编造财报/数据源。
4. **条件引用同规则校验**：`_check_references` 新增 condition 位置；结构化分类来自新增 `ledger.classify_reference`（additive；`validate_reference` 语义未动）。校验结果 `by_position: {supporting/contradicting/condition: {valid/dangling/future/unknown_time/unverifiable_cutoff}}` + 平铺 `dangling/future/unknown_time/unverifiable_cutoff/conflicting`；条件引用可不填，填入即校验（悬空/未来/未知时间全覆盖）。
5. **覆盖缺口入评估**：证据账本的 coverage_notes **逐条原样**带入 gap（`evidence_coverage_note`，上限 12 条+溢出说明）；事件级 failed/partial/unknown 状态独立成 gap（`failed_evidence_event`，不再只看 source_statuses）；`no_bundle`/来源失败照旧。分类是结构化的，不依赖 sentinel 字符串匹配。
6. **缺/非法分析时点不得 assessable**：`_valid_analysis_date` 校验 trade_date；缺失/非法 → `analysis_date` 保持 unknown + gap `analysis_date_unverifiable`；引用判定为 `unverifiable_cutoff`（存在≠时点通过），状态 limited。

**结构化缺口**：卡片新增 `assessment_gaps: [{code, detail}]`（结构化分类，Codex 建议的"结构化原因类别"），`assessment_reasons` 保留为面向人的 detail 列表（旧断言/渲染兼容）。完整显式控制例（有效期限+全要素含来源的条件+有效条件引用+无覆盖缺口+有效分析日）→ `assessable`，`assessment_gaps == []`。
