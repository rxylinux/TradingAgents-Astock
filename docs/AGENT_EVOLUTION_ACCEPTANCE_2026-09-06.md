## 已接受的取舍与未验证能力

- 完整差异在 Web 直接展开，下载保留全文；长报告页面可能较长，折叠不是本轮验收阻塞项。
- CLI 只对存在的输出执行 samefile 硬链接检查，符合文件语义；路径检查与写入之间仍不抵御外部进程刻意替换链接的竞态。
- Web 结果绑定点击时的路径，不监控外部编辑同一路径的文件；新版本存档不会被正常重复运行覆盖。
- 配置指纹覆盖公开白名单，不证明私有端点、凭据、代码、实时数据或实际后备供应商相同。旧断点没有档案时保持未记录，不补造原配置。
- 质量卡表示报告完整性；本轮没有真实模型效果评测、真实行情验证或收益提升证据，也没有成本/性能提升结论。
- 未验证 Windows 文件锁、真实 SDK 子进程及完整 Docker 部署；未迁移用户旧记忆或断点。质量卡 PDF 内容通过共享渲染路径和离线测试检查，本轮未作 PDF 字体/分页的完整视觉验收。
