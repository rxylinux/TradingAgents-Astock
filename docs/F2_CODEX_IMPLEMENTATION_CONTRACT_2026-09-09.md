# F2 Codex 实施契约：只读历史复盘投影

Codex维护，优先于F2草案冲突条款。F1独立验收后即可实现，无需另等用户。只把F1的合规历史记录接入既有决策提示词；F3另审，不更改生产记忆格式、不迁移旧数据、不新增模型/网络调用。

1. **入口与默认行为**：单一可选配置review_records_path，缺省对stock/index都关闭。正常fresh准备期在模型调用前读显式文件，沿F1原始字节/条数上限、UTF-8和全部记录校验；坏输入fail-fast，不降级为空文件。CLI/Web至少提供与D2同风格的显式入口或明确配置传入演示；不写全局配置，不自动扫描历史目录。默认关闭原有past_context/模型调用/图拓扑不变。
2. **F1与F2分层**：F1是相关性排序；F2投影明确仅同ticker和instrument_type。先校验整个输入，然后在limit前执行可信标的/类型过滤，再对匹配集合调用F1时点检索，最后最多5条投影；不能先限量再过滤而漏掉合格记录。异标的/类型单列计数，不拿其未来标题/观点/收益进提示词。as_of、ticker/type、ranking_version均取可信运行准备上下文，不由文件覆盖。F2不传query_window，明确not_requested，不能臆造预测期限。
3. **独立state与摘要**：review_projection为独立持久结构，不把文本拼入past_context。包含已知schema_version、run绑定、可信标的/类型/as_of、投影策略、ranking版本、原始文件input_digest、选中合规记录的必要快照、排除统计/limit信息、局限与payload_digest。摘要精确覆盖全部规范payload（除摘要自身），包括任何会进入提示词的文本；或不保存text、只从经过校验的快照确定渲染。不得持久一个自称result_digest但无对应结果可复算的空锚。
4. **独立元数据锚定**：fresh在run_metadata中记录F2 enabled/schema、input_digest、payload_digest及可信上下文作为独立比较锚；面板自带run_id不等于已证明归属。校验state/run_metadata可信run非空、标的/类型/as_of一致、两个摘要/版本/策略一致、payload自身digest复算、嵌套结构合法。无锚、异run、错类型、未知schema/ranking、正文/记录/统计篡改都不得放行。由新的运行身份建立fresh绑定，两个并发run不串数据。
5. **真正恢复纯读**：_safe_resume_checkpoint在任何模型调用前校验持久F2结构，绝不重读review_records_path、不重新检索当前文件，不因文件删改刷新旧投影。保存运行模式锚点，配置开关与断点模式失配明确拒绝（新旧规则都写清）；真正无F2的旧断点在关闭模式兼容，不用恢复时才提供的文件补历史记录。存在但损坏不清空、不伪装缺失，断点原样保留。实际SQLite关闭重开+prepare+invoke(None)证明完成续跑且已完成节点不重跑。
6. **提示词入口自身验证**：RM、stock Trader/PM和index Trader/PM共五个真实工厂使用同一验证+投影helper；直接调用工厂时也不能把未验证state的text直接拼接。invalid投影返回受控说明、无数值/历史标注正文；准备/恢复遇坏投影则fail-fast。模型调用次数与原流程相同。只渲染F1合规选中记录与必要来源/时间/单位/availability，不把整个raw记录表或被排除内容发给模型。
7. **三态与预算**：关闭→无提示词块、报告未记录；开启零合格→非空限制块，保留排除分类及“无合格不等于历史无事件”；有合格→最多5条、单行160字符、总1200字符（包括标题、限制、截断说明）。限制优先预留，避免长记录冲掉；值为null明确unknown，不把模型自述/外部标注当校准胜率。声明publication/版本可用性来自输入，declared_only不升级为verified历史事实，盈利不等于推理正确。
8. **保留既有记忆语义**：past_context仍由现有生产记忆生成、按原流程刷新与拒绝陈旧；F2通过独立通道在提示词组装层合并。记录投影不能覆盖原有记忆限制，原记忆刷新也不能清除投影；恢复时两者分开验证。TradingMemoryLog源码及用户记忆内容不改。测试给真实一致的历史上下文替身，避免None/空串fixture差异掩盖F2路径。
9. **出口与可复核性**：统一运行JSON保存payload与锚点，Web/MD/PDF共用渲染三态，包含输入/投影摘要、策略、时间边界、选择/排除统计与限制；本机文件路径不进提示词。原始文件只读，渲染不造证据来源。正常CLI/Web配置输入通过真实prepare进真实工厂与报告，不能只写离线helper声称生产集成完成。
10. **离线独立验收矩阵**：默认stock/index关闭零新增调用；启用同标的/异标的混合且超过limit时仍正确选择；五种F1时间门、未来标注及零记录限制在实际提示词可见/不可见；直接工厂错误run/摘要/text无数值；fresh坏文件零模型调用；两个fresh同文件数值相同run不同；真实SQLite恢复删文件零读取、执行完成并保留payload；开关/版本/身份/嵌套内容篡改拒绝且断点保留；past_context更新不覆盖投影；五真实工厂调用计数；三出口三态；CLI正常与坏输入；生产memory源码哈希不变。合成验证只证明工程契约，不代表预测效果改善。

已决：默认关闭；只同标的同类型投影；先过滤再limit；独立state通道；payload规范摘要+run_metadata独立锚；恢复不读原文件、不补卡；五工厂共用验证；三态与1200字符总限。F1通过后立即分小批实现，稳定交接时Codex审核，ZCode继续F3不冲突设计。
