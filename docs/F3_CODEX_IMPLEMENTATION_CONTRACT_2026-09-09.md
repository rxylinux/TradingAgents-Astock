# F3 Codex 实施契约：离线配对评估

Codex维护，优先于F3草案冲突条款。F2独立验收后立即实现，无需再次等待用户。本批是有限队列A/B1/C1/C2/D/E/F的最后一批；完成独立验收后收口，不自动扩展新功能。

1. **可用的离线流程**：提供纯API及实际CLI两阶段：prepare读取显式特征、试验配置与时间切分，输出不可变评估计划；score读取已经冻结的计划、两臂预测文件与独立标签，输出JSON+Markdown。prepare不接受标签路径、不打开标签文件，不读F1完整resolved记录、不调用模型或取数、不改变生产默认流程/记忆。合成示例用预录两臂输出演示，不把替身的差异称为真实E开关实验。实模型生成/调参/自动上线不在F3范围。
2. **结构化特征与版本时间**：独立严格schema，仅允许feature_id、可信instrument/type、prediction_at、feature_available_at、decision（rating/horizon/decided_at）、显式target_window及可选预先声明binary_event定义。字符串/版本/有限非bool数值、UTC偏移、上海date精度沿F1原语。feature_available_at是此特征版本可知时间，不能从F1结果版本倒推或用decided_at替代；两者均不得晚于prediction_at。未知时点明确排除并保留ID/原因，坏格式拒绝。禁止outcome/annotations/labels及派生统计进入特征，额外键包括嵌套额外键拒绝；传入完整F1记录应失败。feature摘要覆盖全部规范特征并复算，不信任声称的摘要。内容字段的白名单不证明真实可用性，报告保留declared_only边界。
3. **固定配对身份和计划分母**：每条计划包含pair_id、feature_id、repeat_index、两臂baseline/candidate；repeat_count显式正整数且非bool，所有预定重复均列入计划。两臂原样normalized_config入文件并复算config_digest，严格比较配置差集只允许顶层evidence_debate_enabled从false到true（必须bool）；其他模型版本、预算、数据、种子策略等全相同，禁止额外字段不同。共享feature快照摘要须一致且能对实际内容复算。拒绝重复身份、声明摘要失配、额外臂/计划外预测；缺失计划内输出计missing，不能缩小计划分母。无记录时合法空报告并所有率为null，不造0准确率。
4. **时间切分与purge**：调用方显式给train/validation/holdout互斥有序日期或时刻区间，按prediction_at分配，边界约定写入报告；无随机切分，无跨界重复归属。按同instrument+type分组，对全部跨切分组合检查闭区间target_window相交，包括train对holdout；从较早切分剔除并逐条记录冲突两侧ID与purged_overlap。判定基于原始全集确定结果，不能随删除顺序改变。embargo默认0，显式非负整数日历日；正值定义为较后切分样本target_window.start向前扩展N个上海日历日再检查早侧窗口，禁止默认为交易日。不同组不互相purge。切分/embargo/窗口均参与计划摘要。purge只控制标签窗口重叠，不宣称经济或统计独立。
5. **冻结预测结构**：每个预测绑定plan_digest、pair/feature/arm/repeat及feature_digest/config_digest，含generated_at（不早于prediction_at）、状态completed/limited/refused/failed、有限有界claims、numeric_references、disagreements、direction或null及usage。stable claim_id需和claim文本摘要绑定，标签必须精确匹配，不靠数组下标。相同身份冲突输出拒绝，不得选最后一个或最好一个；缺失输出由计划补missing状态。评分不重写输出、不产生新预测。声明generated_at与摘要只能证明输入自洽，不能证明过去真的冻结或模型未偷看标签，报告明确说明。
6. **独立标签归属与可知性**：标签独立schema与输入摘要，具有label_id、标注者身份、label_available_at及完整pair/feature/arm/repeat和claim/reference/disagreement ID（运行级标签明确run scope）。精确匹配对应冻结对象，冲突重复标签拒绝，孤立/错臂/错重复/错文本摘要标签拒绝或明确隔离为invalid_label，不能应用到其他臂。评分as_of显式传入：标签可用时间不得晚于as_of；方向/binary outcome类另需显式maturity、observed、publication且全部不晚于as_of，未知或未到期分别pending/unverifiable。事实支持标签不套outcome到期门。预测缺失/失败不允许标签伪造一个成功输出。模型自述不能充当独立事实标签。
7. **指标明确单位与覆盖率**：每臂按完整计划保留planned/missing/failed/refused/limited/completed计数，completed是产出符合schema的结构化结论，不等于被标签评为正确，也不等于非拒答。每指标输出numerator、denominator、value（分母0为null）、eligible/unlabeled/pending/unverifiable，定义不可混用。事实支持率=supported主张数/已评估主张数；数值错误率=外部核验错误引用数/已核验引用数；时点违规率=至少一项独立时点违规的运行数/已审核运行数，多违规不重复算分母；E unresolved与inconclusive分别计数，分母为已列出的disagreements，valid evidence ID不等于resolved，未启用E的分母0/null；方向命中=方向一致数/成熟且可评估方向数，Buy/Hold不隐式映射涨跌。上述率和相应全量覆盖率同表展示，拒答/无标签不能被过滤掉。Brier/校准仅对预测前已有二元事件定义、合法概率[0,1]、成熟二元标签计算；无合格事件为not_applicable，不拿方向rating计算。可先交全部基础指标，Brier若未实现则明确不支持，不得声称F3完整包含校准。
8. **重复与成本**：保留所有重复的原始指标；汇总按同pair/arm的有效单次value给均值、总体标准差（除N），另报有效N/计划N和全部缺失计数，不以0填缺失、不挑最好一次、不宣称置信区间或显著性。每项usage的已知总和、未知条数分开，logical模型调用/实际HTTP请求/工具调用/token不可混算。费用使用Decimal精确累计，按币种分桶，混合币种不相加；部分已知总和不能命名完整总成本。缺耗时为null，不以score脚本耗时冒充模型运行延迟。对缺失输出也保留成本不可知状态，预算上限不冒充消耗。
9. **确定性、边界和CLI**：规范JSON摘要、稳定排序和schema版本沿既有约定；结果摘要覆盖计划/特征/预测/标签/评估参数的实际内容身份，非空假摘要拒绝。同输入同as_of两次输出逐字节一致，不写当前墙钟到结果；保存输入与原始逐次数据供复算。至少2MB/输入、1000 features、100 repeats、20000 planned-arm-runs、100 claims/输出等显式上限并在展开前检查，NaN/Infinity、bool版本/计数、非法Unicode/类型受控拒绝。真实CLI坏输入exit2+简明stderr、无Traceback/成功报告，正常输出JSON与Markdown，输入只读。报告固定“合成契约演示，不代表预测效果提高；准确度与覆盖率同报；盈利不等于推理正确”，实外部预测也需明确来源声明与未验证边界。
10. **交付与验收**：实现集中在evaluation离线模块、测试和合成fixtures，CLI可模块入口；不得把F3接入生产模型路径。必须有真实两阶段CLI、生成阶段未读标签/未触模型的探针、未来特征版本与未来标签分离、同配置唯一bool差异、计划缺失输出分母、跨臂错标签、三个切分非相邻重叠与边界相等/跨标的不purge、重复反序稳定、手算混合拒答/无标签指标、未知usage和异币种、空数据/坏输入exit2与摘要篡改拒绝测试。按F3a计划/身份/切分、F3b评分/报告连续编码，两段分别定向交接，稳定后Codex独立审核及全量。任何合成绿测仅验工程契约。

已决：首批唯一开关E；两阶段离线预录输出评估；feature版本时间独立；所有跨切分同组purge；embargo=0日历日默认；计划分母不缩水；外部标签精确对象绑定；全重复均值及总体标准差；按币种成本；不自动调优或新增模型调用。F2验收前本契约仅用于设计调和。
