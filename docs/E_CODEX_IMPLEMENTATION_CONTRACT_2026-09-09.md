# E Codex 实施契约

本文件由 Codex 维护，优先于 ZCode 草案冲突条款。按本契约实现第一版独立初判与有界新闻反证补查；不更换数据源/模型，不声称投资效果。D2 独立验收通过后开始代码，先 E1 初判/分歧、再 E2 受控工具补查，每阶段交接后继续未冲突的下一阶段。

1. 默认 evidence_debate_enabled=False，原有拓扑/调用/状态行为保持；开启才注册 E。bull/bear 在同一已完成分析师与 C1 证据快照上并行各给一次结构化初判，互不含对方输出。分别使用投影，不把整个 state 直接格式化给模型。二者完成后独立分歧规划节点一次结构化调用，再进入补查与原辩论。增加的逻辑模型调用明确为最多三次（初判2+规划1），不得声称“沿用既有所以零新增”。已有辩论轮数不增加。
2. 初判和分歧使用已有 role provider 与 B1 重试机制，每次输出上限2048 tokens；不得修改共享客户端可变配置，使用正常构造/绑定配置。三次逻辑调用包含各自有界重试/结构化后备，实际请求数另计；usage unavailable 记unknown不能零，语义解析失败不再启动新的纠错LLM链。只记录已知 token，不能用配置上限冒充实耗；预算上限为输出约束，不声称输入token也受该上限控制。
3. 初判保留有问题的主张原文和结构化校验状态，不通过删掉所有无有效引用主张制造高合规率。引用ID/时点有效不等于语义受支持；模型自述信心统一标uncalibrated。每方最多10主张、每主张5引用；文本长度/总量有限，截断明示，缺口保留。
4. 分歧规划输出 question、disagreement_index、decision_impact/answer_changes、tool_name、tool_args。最多前2个合格问题进入补查，超出标not_rechecked，空impact/越界index/非法schema标unresolved。第一版固定2上限无需配置旋钮；只允许当前图实际启用且支持C1 artifact的 get_news/get_global_news 两个工具，不拓宽注册面。规划直接给参数，代码确定性验证后发起调用，不另加“提问节点”LLM。工具不支持的问题留下明确缺口。
5. 每问题至多一次实际工具invoke，总至多2次，不是“一轮任意多tool_calls”。禁同轮批量/无限重试/外部工具链。仅允许已验证参数、可信标的与运行日，调用前按C1规则收窄时间；无法校验则不调用。limit/lookback等工具参数设合理有限上限并注明，模型不能提高。工具自己既有网络重试与一问一次工具调用分开计数，不能声称一次外部HTTP。默认离线验收，开发不访问实际新闻/模型。
6. 使用C1 artifact/delta路径将新证据绑定本run和稳定question/tool_call_id，旧证据/新证据区分。C1 ID是来源相关的，不可假定跨源转载相同ID；第一版不按数量投票、不算独立支持票，未知来源关联保持unknown。可标相同规范内容digest的重复，但不同摘录不能仅因相似就宣称独立/同源。未来正文不得进入初判/规划/回流提示词。
7. 第一版不做一般文本的自动resolved_side判定：结果为retrieved/inconclusive/unresolved/error/budget_exhausted等可观测状态，新引用附校验结果，双方数值与观点并存；“拿到有效引用”不等于争议解决。去除以引用成立/失效选择bull/bear的逻辑。解释/事实支持判断保留为待人工或后续独立标注，不增加LLM裁判以自评成功。
8. 已完成初判、问题、调用标识与预算进入持久state，真实checkpoint恢复不重复已完成模型/工具节点，不归零预算；重复artifact事件幂等。对外部调用已发出但未落checkpoint的崩溃窗口，不宣称exactly-once；记录限制并用保守inconclusive处理或明确只保证已持久结果不重放。fresh并发不同run隔离，默认关闭旧断点兼容，开启配置/阶段不匹配拒绝以免切换拓扑错误恢复。
9. 输出E结构通过统一JSON、Web/MD/PDF共用渲染保留：双初判、分歧与校验、问题是否补查、tool执行与失败、未解决原因、已知调用/token统计和unknown。E不得覆盖C2评估状态或D数值，不自动交易/提醒。已有RM/辩论提示词显式看到E受限摘要，不能只落盘却完全无下游消费；摘要不能冲掉原数据限制。
10. 真实离线验收：默认图调用序列相同；两初判完全互盲；新增逻辑调用<=3且实际替身计数一致；5个问题/未知工具/非法参数/越界日期/多toolcalls不超过2次实际工具invoke；两种新闻真实ToolNode到C1 artifact通路；重复来源不投票；合法引用不自动resolved；零可用工具/供应商失败留下限制；interrupt后resume执行完成且已完成节点计数不增加；两并发run隔离；三出口一致。E-on/off同模型/fixture预算条件配对报告仅契约指标，不能自动判优或推广默认。

四个决策已定：独立规划节点；固定最多2问题；首批仅当前启用新闻artifact工具；禁止用ID/时间合法性自动裁决语义争议。可据此连续实施，不再等待用户确认。稳定小批交接后Codex独立审核，ZCode继续不冲突的后续任务；不得重复跑全量等待或绕过已知失败进入后批。
